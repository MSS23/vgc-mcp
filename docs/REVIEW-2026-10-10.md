# Review — 2026-10-10

## What the project is for

An MCP server that gives any LLM client Showdown-accurate VGC tooling: Gen 9
damage calcs, EV/SP spread optimisation, Smogon usage stats, team analysis,
replay analysis and a live battle copilot. It covers both mainline VGC (EVs)
and Pokemon Champions Reg MA/MB (Stat Points). It is hosted as a public Claude
connector at `https://vgc-mcp.onrender.com/mcp`. The users are competitive
players who want calcs and spreads they can paste straight into Showdown.

## What changed

1. **PokeAPI client contract (the main bug).** About 24 tools were broken in
   production. `get_pokemon` returned raw PokeAPI JSON, but callers indexed
   `base_stats` and flat `types`. `get_pokemon_stats` and `get_nature` were
   called but did not exist. Unit tests mocked the shape the callers wanted,
   so the suite stayed green. The fix is in the client, which every caller
   goes through: `get_pokemon` adds normalized `base_stats` and `types`, and
   the two missing methods now exist (`get_nature` reads the local nature
   table and makes no network call). `tests/api/test_pokeapi_contract.py`
   runs the tools against the real client with only `_fetch` patched. It
   fails on the old code.
2. **Gen 9 weather chip.** Snow now deals no chip damage; only legacy Hail
   does. Ice Body heals instead of being reported as immune. `"sand"` is
   accepted as Sandstorm; before, it silently returned 0.
3. **`serverInfo.version`** now reports the package version.
4. **Smogon 404 negative cache (1 h).** Missing months and formats were
   re-requested on every usage lookup.
5. **HTTP boundary.** The bearer token is compared in constant time as bytes.
   The rate limiter prunes expired per-IP buckets, which used to grow without
   bound.
6. **Docs drift.** Tool counts (208 → 213), the dead Discussions links and the
   missing Smithery icon. The CI mypy baseline was lowered from 1149 to 1134
   (1132 locally).

Verification: `ruff check src tests scripts` passes, mypy reports 1132 errors
(down from 1147), and `pytest` gives 3,763 passed and 14 deselected
(integration). A local `vgc-mcp-http` smoke run listed 213 tools, reported
`serverInfo.version` 1.0.1, and the previously failing tools returned results.

## Remaining suggestions (ranked)

| # | Suggestion | Effort |
|---|---|---|
| 1 | **Shrink the tool surface.** 213 tools / 278 KB of schemas use a large share of the client's context before the first question. Offer a "core" profile (about 30 tools: calc, spreads, speed, usage, team, battle) through an env var or a second endpoint, and merge near-duplicates (`optimize_bulk` / `optimize_bulk_math`, `outspeed_probability` / `analyze_outspeed_probability` / `outspeed_probability_stored`, `suggest_spread` / `suggest_ev_spread` / `suggest_spread_for_role`, `get_speed_tiers` / `get_meta_speed_tiers`). | L |
| 2 | **Map `PokeAPIError` to `pokemon_not_found` with suggestions.** Unknown names currently surface as `internal_error: Not found: pokemon/x`. The `if not data:` checks after `get_pokemon` are dead code because the client raises. One `except PokeAPIError` in the shared tool error path would fix every tool. | S-M |
| 3 | **Item and chip tools ignore Champions.** `calculate_assault_vest`, `calculate_eviolite`, the chip HP maths and others use the mainline EV/IV formula inline. Route them through `calculate_all_stats`, which already dispatches on `format_system`. | M |
| 4 | **Tests should mock at the network edge, not the client API.** This bug lived because `AsyncMock()` accepts any method name. Use `AsyncMock(spec=PokeAPIClient)` in tool fixtures (a one-line change per fixture) so calls to methods that don't exist fail. | S |
| 5 | **Rate limiter trusts the leftmost `X-Forwarded-For`**, which the client controls, so the limit can be bypassed by rotating the header. Use the proxy-appended (rightmost) hop once Render's hop count is confirmed. | S |
| 6 | **Split the giant tool modules**: `spread_tools.py` (4.7k lines), `workflow_tools.py` (3.8k), `damage_tools.py` (3.1k). Move logic into `vgc_mcp_core/tools/*_handlers.py` as CLAUDE.md prescribes. | L |
| 7 | **Keep working down the mypy debt** (1132 strict errors). Fix it per package, starting with `api/` and `calc/`. | L |
| 8 | **Dockerfile**: run as a non-root user, drop `curl` (use a Python health check) and use a non-editable install. | S |
| 9 | `damage.py` gives Ice types the 1.5x Defense boost under `"hail"` as well as `"snow"`. Gen 9 Hail no longer exists, so restrict the boost to snow. | S |
