# Calculation and common-set audit — 5 September 2026

This audit exercised the calculation engine, spread consumers, Smogon client,
and existing server/team/import/export tests. Changes are local to this checkout.

## Corrections

- Chaos move and teammate percentages now divide by weighted Pokemon occurrences.
  A move on every set reports 100%, rather than roughly 25%. Empty move slots are
  excluded. Common-set output explains that components are independent rankings.
- Trend comparisons use the resolved data month, then the preceding calendar
  month on the same ladder at the same cutoff. Publication delays no longer
  cause self-comparisons. Historical lookups preserve the active source metadata.
- Invalid JSON and non-chaos responses are rejected without poisoning the cache.
- Damage uses the attacker's level instead of a hard-coded level-50 factor.
- Stat modifiers are chained before rounding. Thick Fat, Heatproof, Water Bubble
  and Purifying Salt modify the attacking stat; Fur Coat modifies Defense;
  Dry Skin modifies base power; Sniper applies its extra multiplier at the final
  damage stage.
- Psyshock, Psystrike and Secret Sword use Defense stages, defensive boosts and
  Sword of Ruin rather than Special Defense modifiers or Assault Vest.
- Ruin holders are exempt from the matching Ruin effect. Ruin remains effective
  on critical hits. Paradox stat ties use Attack, Defense, SpA, SpD, Speed order.
- Commander and defensive Embody Aspect boosts are stat stages. They combine
  with other stages and obey critical-hit rules. The old Cornerstone test
  incorrectly expected Surging Strikes to respect a positive Defense stage;
  it now checks both critical and ordinary hits.
- KO probabilities count exact independent outcomes using a bounded damage
  distribution. Ten-hit calculations avoid enumerating 16^10 outcomes.
  Multi-hit 2HKO/3HKO/4HKO verdicts describe repeated uses of the complete move.
  Near-certain outcomes are no longer labelled guaranteed.
- Survival and KO consumers use exact outcome counts instead of counting the
  16 representative display values for multi-hit attacks.

## Remaining limits

These checks establish regression coverage for the cases described above;
they do not certify every interaction in a complete battle simulator.

- Multi-hit probability is conditional on the chosen hit count and identical
  per-hit modifiers. Accuracy, random hit counts, consumed berries, loss of
  Multiscale, and other between-hit state changes need separate modelling.
- Parental Bond still uses the existing approximate second-hit calculation.
- Some spread-search paths use defensive-ratio approximations to select
  candidates. Exact damage is required to verify a candidate's benchmarks;
  this audit does not establish global optimality for those searches.
- Historical usage means the most recent available data for that regulation,
  which can be several months old, as the Reg I live check demonstrates.
- Chaos provides marginal frequencies, so an assembled popular set is a
  recommendation and cannot be described as an observed complete set.
